Longhorn v1 Data Engine 使用实践

Longhorn 是一款专为 Kubernetes 设计的云原生分布式存储系统，提供简单易用、高可靠性的持久化存储能力。

本文基于 Longhorn v1 Data Engine 进行实践。

环境信息

  • Longhorn：v1.12.1
  • Kubernetes：RKE2 v1.35.8+rke2r1
  • 集群规模：3 个节点
  • 节点规格：每个节点 4c8g

会部署以下组件：

组件 运行方式 作用
csi-attacher Deployment 监听 VolumeAttachment，负责 Volume Attach / Detach
csi-provisioner Deployment 根据 PVC 创建 Longhorn Volume
csi-resizer Deployment 处理 PVC 扩容请求
csi-snapshotter Deployment 创建和管理 Volume Snapshot
longhorn-csi-plugin DaemonSet Kubernetes CSI Node Plugin，负责 Volume mount / unmount
longhorn-manager DaemonSet Longhorn 核心服务，管理 Volume、Engine、Replica
engine-image DaemonSet 提供 Longhorn Engine 运行镜像
instance-manager DaemonSet 管理 Engine 和 Replica 进程生命周期
longhorn-driver-deployer Deployment 部署 CSI Driver 相关资源
longhorn-ui Deployment Longhorn Web 管理界面

RWO 类型的 Volume

Longhorn RWO 的核心是工作负载所在节点直接把 Longhorn Volume 当成块设备挂载，依赖 iSCSI：

可以看到 Engine 是运行在 Pod 所在节点的 Instance Manager 中：

Pod 所在节点可以看到对应的块设备 /dev/sdc，以及 iSCSI 信息，10.42.179.63 为 Pod 所在节点的 Instance Manager Pod IP：

RWX 类型的 Volume

Longhorn 的 RWX 不是让多个节点直接连接同一个块设备，而是启动一个 Share Manager Pod 提供 NFS Server 服务，Pod 通过 NFS Client 挂载 Volume 使用：

默认情况下，NFS Client 通过 Share Manager 的 Service 连接，所以依赖 CoreDNS。

如果要使用真实 IP 地址，则需要配置 Storage Network，具体配置参考：https://warnerchen.github.io/2025/11/28/Longhorn-%E9%85%8D%E7%BD%AE-Storage-Network/

除了普通类型的 RWX Volume 外，Longhorn 还提供 Migratable RWX，这种类型仅适用于 KubeVirt VM 的热迁移，不适合作为普通共享文件系统使用。
